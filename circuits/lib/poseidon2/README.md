# Poseidon2 (BN254, t=3)

Vendored from [`@taceo/circom-lib`](https://www.npmjs.com/package/@taceo/circom-lib) v0.6.0
(`circuits/poseidon2.circom`, `circuits/poseidon2_constants.circom`), MIT licensed — see
`LICENSE-taceo-circom-lib`. Round constants and the internal-matrix diagonal are generated by the
[HorizenLabs Poseidon2 sage script](https://github.com/HorizenLabs/poseidon2), matching the
[Poseidon2 paper](https://eprint.iacr.org/2023/323) parameters and cross-checked against the
[`@taceo/poseidon2`](https://www.npmjs.com/package/@taceo/poseidon2) TypeScript reference (parity
with the Rust `taceo-poseidon2` crate) — see
`docs/research/2026-07-30-poseidon2-merkle-hash.md` for the independent test-vector check performed
before this template touched any production circuit.

Only `t=3` (2-to-1 hash, used for the depth-20 Merkle accumulator) is wired into Veil circuits.
`t=2,4,8,12,16` are present in the vendored file but unused and untested here — do not assume they
are verified for this codebase.

Unmodified from upstream except this README and the two-file copy itself.
